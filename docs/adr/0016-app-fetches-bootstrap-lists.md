# Bootstrap List 由应用拉取，Pack 自带快照

BT 的 Tracker 列表和 eD2k 的 `server.met`、`nodes.dat` 都由应用经全局代理拉取，按订阅地址缓存为磁盘文件，
引擎只加载本地文件。每个 Pack 自带一份内置快照，没有缓存时使用。刷新在 Pack 激活后于后台进行，过期时间一天，
新建 Task 和启动引擎都只用当前已有的列表，从不等待拉取。

## Considered Options

- **交给 goed2kd 在启动时自己下载**（本 ADR 前 eD2k 的做法）：不走代理、没有缓存，下载失败或一个服务器都连不上就让
  goed2kd 启动失败，所有 eD2k Task 随之报错；界面也拿不到任何状态。
- **首次使用时等第一次拉取完成**：离线、首次启动、所有订阅都失败时仍然没有列表可用，且新建 Task 被网络拖慢。
- **缓存存进配置文件**（本 ADR 前 BT 的做法）：配置文件变成数据仓库，二进制文件要 base64，更新时间和条数要另存，
  容易与内容不一致。

## Consequences

- 更新时间取缓存文件的修改时间，条数在加载时计算；失败原因只在本次运行中保留，不弹 Notice。
- 内置快照需要在发版前用脚本更新。
- DHT 引导节点不是 Bootstrap List，保持为代码常量。
- 应用交给 eD2k 引擎多个本地列表文件，需要 goed2kd 0.2.4 及以上；换成 Kelpie 后由它的 Python 包在握手时检查版本。

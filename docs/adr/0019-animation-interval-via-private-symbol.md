# 高刷屏动画间隔靠 Qt 私有符号调整，只在 Windows 上做

Qt 的属性动画（平滑滚动、切页、对话框开合）统一由 `QUnifiedTimer` 驱动，间隔写死 16ms，高刷屏上所有动画都被锁在 60 FPS。Qt 没有公开接口改它，PySide6 也没绑定，只能用 ctypes 按 `Qt6Core.dll` 导出的 MSVC 修饰名调用 `QUnifiedTimer::setTimingInterval`。

启动时按主屏刷新率设一次（160Hz 取 6ms），不跟随窗口换屏。找不到符号（Qt 升级改名、DLL 不同）只记警告，保持默认 16ms，不影响功能。

只做 Windows：修饰名按编译器不同，且滚动和对话框的配套优化（不透明滚动内容、整像素滚动）依赖 Windows 的光栅后备缓冲，macOS 和 Linux 都没验证过。

考虑过动画运行时把间隔压到 1ms、每跳立即重绘：帧率再高约 10 FPS，但要跟踪全部动画的启停，强制重绘还会画出排到一半的嵌套布局（设置组展开时标题跳动），放弃。代价是不确定进度条也按刷新率重绘，比 60 FPS 时多耗一些 CPU。

升级 PySide6 后若动画回到 60 FPS，先查日志里有没有这条警告。

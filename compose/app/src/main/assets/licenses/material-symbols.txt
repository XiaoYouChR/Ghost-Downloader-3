SVG viewBox 0 -960 960 960 is preserved with a translateY=960 group.
Default axes: weight 400, grade 0, optical size 24, fill 0.
Navigation selected variants use fill 1. Intrinsic display size: 24dp.
Directional back, chevron and sort resources enable Android autoMirrored.

# Contributing to Ghost Downloader

## AI 工具使用政策

### Pull Request

PR 中使用了 AI 工具时，请在 PR 模板的 "AI 工具使用" 中如实声明：

- **辅助开发**：代码补全、查用法、辅助调试等，勾选即可。
- **主要生成**：生成了大量代码或核心逻辑，需注明工具和模型，如 `Cursor + Claude Sonnet 4`，不确定写"模型未知"。

### Issue

不要用 AI 代写 Issue，也不要粘贴 AI 根因分析、源码解读、修复建议或技术方案，非中英文母语者仅限纯翻译。Bug 报告只需提供现象、复现步骤、链接和原始日志；功能需求只需说明场景和痛点。违反者可能被直接关闭。

## 贡献者许可协议（CLA）

首次提交 PR 时，CLA Assistant 会请你签署 [贡献者许可协议](https://gist.github.com/XiaoYouChR/45552e04f1ba6234fa372e11e37dc91d)。

### 为什么？

引擎（`app/` 中桌面界面以外的部分和 `features/`）也会用在不开源的移动端里。CLA 让你的贡献可以随引擎一起进入移动端。

### 桌面版和引擎仍然开源吗？

是。公开仓库中的代码始终以 GPL v3 提供，CLA 第 7 条对此做了承诺。

### 只改桌面界面需要签吗？

只改 `app/view/` 的 PR 不会进入移动端，不签也可以合并。

## 从源码运行 cli

```sh
uv run Ghost-Downloader-3.py ghd --help
```

## AI Tool Usage Policy

### Pull Requests

If AI tools were used in a PR, disclose it in the "AI Tool Usage" section of the PR template:

- **Assisted development** — code completion, API lookups, debugging, etc. Just check the box.
- **Primarily generated** — significant code or core logic generated by AI. Specify the tool and model, e.g. `Cursor + Claude Sonnet 4`, or "model unknown".

### Issues

Do not use AI to write issues or paste AI root cause analyses, code explanations, fix suggestions, or technical proposals; non-native Chinese/English speakers may use direct translation only. Bug reports only need observed behavior, steps, source URL, and raw logs; feature requests only need your use case and pain points. Violating issues may be closed directly.

## Contributor License Agreement (CLA)

When you open your first PR, CLA Assistant will ask you to sign the [Contributor License Agreement](https://gist.github.com/XiaoYouChR/45552e04f1ba6234fa372e11e37dc91d).

### Why?

The engine (`features/` and everything in `app/` except the desktop UI) is also used in a mobile app that is not open source. The CLA lets your contribution ship there along with the engine.

### Are the desktop app and the engine still open source?

Yes. Code in the public repository is always available under GPL v3, as promised in section 7 of the CLA.

### Do I need to sign for desktop UI changes only?

PRs that only touch `app/view/` never reach the mobile app and can be merged without signing.

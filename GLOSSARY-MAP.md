# Glossary Map

## Contexts

- [Ghost Downloader](./GLOSSARY.md)：桌面应用与共享的业务引擎
- [Browser Extension](./browser_extension/GLOSSARY.md)：捕获页面资源并发送到桌面应用
- [Compose](./android/GLOSSARY.md)：Android 端

## Relationships

- **Browser Extension → Ghost Downloader**：共享 Resource 与 Task Options 的定义
- **Compose → Ghost Downloader**：继承全部领域语言，只补充 Android 专有的术语

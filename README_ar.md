## الميزات

* تقسيم ذكي للتحميل على أجزاء متعددة⚡ بدون دمج ملفات، مع تسريع ذكي مدعوم بالذكاء الاصطناعي 🚀
* يحرر واجهة المستخدم عند التصغير إلى علبة النظام🍃 — ذاكرة footprint ضئيلة في الخلفية
* يدعم HTTP و Magnet / BT و FTP و M3U8 و MPEG-DASH و eD2k والمزيد 🌐
* يحاكي بصمات TLS للمتصفحات الحقيقية🥷 لذا فإن التحميلات أقل عرضة للحظر من قبل فحوصات مكافحة البوت
* يحلل فيديوهات YouTube▶️ و Bilibili — قوائم تشغيل، حتى 4K/HDR، وترجمات وتسجيل دخول مدعومة
* محللات مخصصة لـ إصدارات GitHub🐙 ونماذج HuggingFace🤗 مع تسريع عبر المرايا
* يسجل بثوث M3U8📺 مع فك تشفير في الوقت الفعلي🔓، مدعوم بالكامل على Android أيضاً
* امتداد المتصفح المرافق🦊 يلتقط موارد الوسائط في الصفحة بتغطية مستوى IDM بدون حد لجودة، يتولى تحميلات المتصفح، ويتحكم في المهام من داخل المتصفح
* واجهة RPC متوافقة مع aria2🔌 — يمكن للأدوات الخارجية إرسال مهام مباشرة
* يمكن إيقاف المهام مؤقتاً وتعديلها✏️ (الرابط، العناوين، البروكسي) واستئنافها دون فقدان التقدم
* إصدار Android📱 كامل مع تحميل في الخلفية وإشعارات عند الاكتمال 🔔

## حول المشروع

* برنامج تحميل مبني من الشغف، وأول مشروع Python لي 😣
* تم إنشاؤه في الأصل لمساعدة منشئ محتوى على Bilibili في دمج الموارد 😵‍💫
* بفضل سهولة الوصول إلى Python🐍، سيفتح هذا المشروع دعم الإضافات🧩 في المستقبل (واجهة برمجة الإضافات لا تزال قيد التثبيت...)

|    المنصة    | الإصدار المطلوب |  البنيات المعمارية   | متوافق |
|:--------------:|:----------------:|:----------------:|:----------:|
|  🐧 **Linux**  |  `glibc 2.35+`   | `x86_64`/`arm64` |     ✅      |
| 🪟 **Windows** |      `10+`       | `x86_64`/`arm64` |     ✅      |
|  🍎 **macOS**  |     `13.0+`      | `x86_64`/`arm64` |     ✅      |
| 🤖 **Android** |     `10.0+`      |   `arm64-v8a`    |     ✅      |

> [!WARNING]
> إصدار Qt `6.6+` لم يعد يدعم المعالجات بدون مجموعة تعليمات `AVX`.

> [!TIP]
> **دعم AUR لـ Arch Linux**: الحزم المُحافظة عليها من المجتمع `ghost-downloader-bin` و `ghost-downloader-git` متاحة الآن (المشرف: [@zxp19821005](https://github.com/zxp19821005))

## المراجع

* [aioftp](https://github.com/aio-libs/aioftp) عميل/خادم FTP لـ asyncio
* [cat-catch](https://github.com/xifangczy/cat-catch) امتداد sniffing لموارد المتصفح
* [desktop-notifier](https://github.com/samschott/desktop-notifier) مكتبة Python للإشعارات المكتبية عبر المنصات
* [FFmpeg](https://ffmpeg.org/) حل شامل عبر المنصات لتسجيل وتحويل وبث الصوت والفيديو
* [goed2k](https://github.com/monkeyWie/goed2k) خدمة تحميل eD2k التي تقف خلف دعم eD2k في Ghost Downloader
* [libtorrent](https://github.com/arvidn/libtorrent) تنفيذ C++ فعال وكامل الميزات لـ BitTorrent
* [loguru](https://github.com/Delgan/loguru) مكتبة تهدف إلى جعل التسجيل ممتعاً
* [m3u8](https://github.com/globocom/m3u8) محلل M3U8 بلغة Python
* [mpegdash](https://github.com/sangoma/mpegdash) محلل MPD لـ MPEG-DASH
* [N_m3u8DL-RE](https://github.com/nilaoda/N_m3u8DL-RE) أداة تحميل DASH/HLS/MSS عبر المنصات التي تدعم تحميل M3U8 في Ghost Downloader
* [Nuitka](https://github.com/Nuitka/Nuitka) مترجم Python
* [PyQt-Fluent-Widgets](https://github.com/zhiyiYo/PyQt-Fluent-Widgets) مكتبة ودجات قوية وقابلة للتوسيد وتصميم أنيق على طراز Fluent Design
* [PySide6](https://github.com/PySide/pyside-setup) الوحدة الرسمية لـ Python
* [QuickJS-NG](https://github.com/quickjs-ng/quickjs) محرك JavaScript صغير وقابل للدمج
* [uvloop](https://github.com/MagicStack/uvloop) حلقة أحداث asyncio فائقة السرعة
* [winloop](https://github.com/Vizonex/Winloop) بديل لـ uvloop لـ Windows
* [wreq](https://github.com/0x676e67/wreq-python) عميل HTTP مريح بلغة Python مع محاكاة بصمة TLS
* [yt-dlp](https://github.com/yt-dlp/ ناسخ سطر أوامر للصوت والفيديو غني بالميزات]
